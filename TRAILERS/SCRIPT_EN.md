# Acid Rain — detailed trailer script

Target: 50 seconds, 16:9, 60 FPS. Tone: calm survival turning into controlled danger.

## Capture preparation

- Use the English release in a dedicated copy of the world.
- Build a small survival base with an open courtyard and a clearly visible roof.
- Prepare the four chemical-protection recipes and one complete set.
- Record one clean daytime establishing shot before changing the weather.
- Setup-only commands: `/function x1miya:acid_rain/force_start`, `/function x1miya:acid_rain/force_stop`, `/function x1miya:acid_rain/status`, and `/function x1miya:acid_rain/test_near_break_armor`.
- The commands are production tools; do not imply that normal players must run them.

## Required proof shots

- Damage happens outside and stops under solid cover.
- Creative/Spectator behavior is not used as proof.
- The complete chemical set is visibly equipped before the protected exposure shot.
- Corrosion feedback is captured from the release build.
- The crafting image matches the in-game recipes.

## Reset after capture

Run `/function x1miya:acid_rain/force_stop`, then `/function x1miya:acid_rain/reset`. Restore clear weather before recording any clean outro pickup.

## Deliverables

- Voice version and clean-text-only version.
- English subtitles.
- 10–15 second vertical cut: exposure → roof → full chemical set → title.
- Thumbnail candidate: protected player in green rain, with no added claim beyond “ACID RAIN”.
