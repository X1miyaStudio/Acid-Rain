# Кислотный дождь — подробный сценарий трейлера

Цель: 50 секунд, 16:9, 60 FPS. Настроение: спокойное выживание постепенно превращается в контролируемую опасность.

## Подготовка съёмки

- Используй RU-релиз в отдельной копии мира.
- Построй небольшую базу с открытым двором и хорошо заметной крышей.
- Подготовь ингредиенты четырёх рецептов химзащиты и один полный комплект.
- До изменения погоды сними чистый дневной общий план.
- Команды только для подготовки: `/function x1miya:acid_rain/force_start`, `force_stop`, `status`, `test_near_break_armor`.
- Не создавай впечатление, что обычный игрок обязан запускать эти команды.

## Обязательные доказательные кадры

- Урон начинается снаружи и прекращается под твёрдой крышей.
- Перед защищённым выходом видны все четыре предмета комплекта.
- Коррозия снята из релизной сборки.
- Сетка крафтов совпадает с игровыми рецептами.
- Творческий режим и Наблюдатель не используются для имитации защиты.

## Сброс

После дубля выполни `force_stop`, затем `reset`, верни ясную погоду и только потом снимай чистые перебивки.

## Итоговые материалы

- Полный RU-трейлер и версия без голоса.
- Русские субтитры.
- Вертикальный ролик 10–15 секунд: урон → крыша → полный комплект → название.
- Обложка: защищённый игрок под зелёным дождём, без лишних обещаний.
